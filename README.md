# Customer-Churn-Prediction-Dashboards
Predictive Customer Churn Dashboard

A Machine Learning-powered Streamlit dashboard that predicts customer churn and provides visual insights into customer behavior.

Features
Upload any CSV dataset
Automatic churn column selection
Data preprocessing and encoding
Random Forest Classification
Churn prediction
Accuracy evaluation
Confusion Matrix visualization
Feature Importance analysis
Downloadable feature importance report
Technologies Used
Python
Streamlit
Pandas
NumPy
Scikit-Learn
Matplotlib
Seaborn
Workflow
Upload customer dataset
Preview dataset
Select churn column
Train Random Forest model
Analyze churn metrics
View feature importance
